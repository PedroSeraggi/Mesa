# Pedidos de imagem das cutscenes

Ferramenta: app do Gemini (gemini.google.com). Cole um prompt por vez.
Dica: depois de gerar o Prompt 1, ANEXE essa imagem nas próximas e escreva antes do prompt: "Use exactly the same art style as the attached image." Isso mantém todas no mesmo estilo.
Se a imagem vier quadrada, peça: "Make it a wide 21:9 landscape."

Salve cada imagem com o nome indicado em: mesa-xmage\web\cutscenes\<pasta>\
